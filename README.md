# Stakeholder Insights & Performance Dashboard 📊

## Overview

This project uses Tableau to analyze stakeholder insights and financial performance across insurers, premiums, profitability, and assets under management.

The interactive dashboard provides key performance indicators (KPIs), visualizations, and dynamic filters to help users explore business trends and support data-driven decision-making.

## Dataset

- **Source File:** `Finance record.xlsx`
- **Format:** Excel
- **Data Type:** Financial and stakeholder data

### Key Data Areas

- Premium collection over time
- Value created by insurers
- Stakeholder distribution
- Assets under management
- Profitability by city and policy tenure
- Cost ratios and profitability

## Tools & Technologies

## Dashboard Features

### Key Visualizations

- **Value Created by Insurer:** Compares value created across insurer channels.
- **Premiums Over Time:** Displays premium trends across years.
- **Profitability by City and Tenure:** Explores profitability across cities and policy tenure categories.
- **Assets Under Management by Stakeholder:** Compares asset distribution across stakeholder groups.
- **Stakeholder Distribution:** Visualizes stakeholder shareholding patterns.
- **Cost Ratio vs Profitability:** Presents cost-ratio and profitability measures.

### Interactive Filters

The dashboard includes filters for:

- Stakeholder
- City
- Assets Under Management
- Gender
- Date
- Premium
- Profitability

Users can explore the dashboard to examine different stakeholder groups and financial metrics.

## Key Results

The dashboard highlights the following business metrics:

## How to Run

1. Clone or download this repository.
2. Install and open Tableau Desktop.
3. Open `Finance record dashboard.twb`.
4. If prompted, reconnect the data source to `Finance record.xlsx`.
5. Refresh the data if required.
6. Explore the dashboard using the available filters and visualizations.

### Prerequisites

- Tableau Desktop
- `Finance record.xlsx`
- `Finance record dashboard.twb`
